A lossless byte↔pixel-grid codec: decode(encode(x)) === x, byte-exact, for any input — not a visual summary, not a vibe. Every frame carries a CRC-16 checksum, so a single altered pixel is caught and named, not silently returned as different-but-valid bytes. This page runs the real kernel below — nothing here is a mockup.
